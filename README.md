Cantabile (Perpetual Cadence) is an offline-first Android music practice tracker and AI lesson analyzer built in React Native, TypeScript, and Expo. <p>
Designed with a low-friction interface to minimize executive dysfunction, it features a timestamp-accurate practice stopwatch with multi-instrument switching, multi-category session tagging, and a 5-minute threshold gate. Rather than punitive daily streaks, progress is tracked via a rolling 7-day consistency window and a polynomial RPG leveling curve backed by a Kimball-style local SQLite star schema with Supabase cloud sync. <p>
On the Lessons tab, users can ingest .m4a or .mp3 recordings—automatically downsampled to 16kHz mono AAC—for music-biased speech-to-text transcription and LLM extraction into structured critique accordions, itemized teacher feedback, and approvable focus tags. <p>
Finally, an integrated ViewShot and custom Kotlin WallpaperManager generator dynamically renders live practice stats, active repertoire, and jury milestones straight to the Android lock screen.
